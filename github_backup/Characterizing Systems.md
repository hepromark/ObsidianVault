1. Time In-variance

*Time invariant system has parameters that do not change with time. An input at time $t_1$ gives output $y_1$. Shifting the input $t_1$ by $T$ will only output the shifted $y_1$ by T*

2. Causality

*Casual if output at any time instance only depends on input of current / past time. Output must start after input*

3. Memory

*Memoryless <=> at every instance, the output depends ONLY on the input at the current time*

4. Invertbility

*Invertible if input x(t) can be recovered from corresponding output y(t)*
-  one-to-one mapping of input -> output required

5. BIBO Stability

*A system has Bounded Input Bounded Output stability <=> every bounded input results in a bounded output*
- Given a finite range of input values, we can prove the system's output will stay inside a finite range

6. Linearity

*The output of a linear combination of inputs is the same linear combination of individual outputs*
